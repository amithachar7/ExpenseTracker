# Expense Tracker

A complete personal expense tracker built with Flask, SQLite, HTML, CSS and JavaScript.

## Features
- Secure registration/login with hashed passwords
- Dashboard with income, expenses and balance
- Add and delete transactions
- Categories and transaction types
- Search and filtering
- Expense category chart
- Monthly income vs expense chart
- Responsive modern UI
- SQLite database
- Demo account with sample data

## Run on Windows
1. Install Python 3.11+.
2. Open Command Prompt in this folder.
3. Create a virtual environment:
   `python -m venv venv`
4. Activate:
   `venv\Scripts\activate`
5. Install:
   `pip install -r requirements.txt`
6. Start:
   `python app.py`
7. Open:
   `http://127.0.0.1:5000`
